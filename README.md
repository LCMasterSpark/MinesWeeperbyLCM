# 扫雷

一个用 WPF 写出来的扫雷小作品。它一开始只是普通的扫雷，后来慢慢长出了不同尺寸的棋盘、多档难度、第一步避雷、街机生命值、隐藏心心补给，还有一点点“？？？”模式的恶作剧味道。

这个项目不追求庞大，但希望每一局都能玩得顺手：小棋盘可以轻松热身，大棋盘可以认真推理，街机模式则更像一场带血条的扫雷挑战。

## 玩法特色

- 多种棋盘尺寸：`5x5`、`8x8`、`12x12`、`15x15`
- 多档普通难度：宝宝模式、简单、中等、困难、大棋盘、巨型棋盘
- “？？？”难度：每个棋盘直接锁定最大雷数，第一步也不保证安全
- 普通模式第一步避雷，减少开局直接失败的挫败感
- 街机模式：
  - 初始 `3` 颗心
  - 固定 `40` 个安全格，棋盘越大雷越多
  - 踩雷扣心，心用完才结束
  - 安全格中有概率藏着心心补给
  - 一局结束后可以直接再来一局，不必回主菜单
- 战绩展示：
  - 普通模式显示最后一局
  - 街机模式显示最近 5 局总览

## 项目结构

```text
扫雷/
├─ App.xaml
├─ MainWindow.xaml        # 主菜单界面
├─ MainWindow.xaml.cs     # 模式、难度、棋盘尺寸选择
├─ Window1.xaml           # 游戏窗口界面
├─ Window1.xaml.cs        # 游戏窗口渲染、点击处理、结算弹窗
├─ Gaming.cs              # 棋盘状态和核心游戏规则
├─ GameStats.cs           # 最近战绩统计
└─ 扫雷.csproj
```

## 运行

```powershell
dotnet run --project .\扫雷\扫雷.csproj
```

## 构建

```powershell
dotnet build .\扫雷.slnx
```

## 小记

扫雷最有意思的地方，是它看起来冷冰冰，实际上每一步都带着一点心理战：这格该不该开？这面旗是不是太自信了？街机模式让这种犹豫更明显，因为你有几颗心可以犯错，但每一次犯错都会被记住。

祝你扫得开心，也祝你别在第一步之外踩雷。
